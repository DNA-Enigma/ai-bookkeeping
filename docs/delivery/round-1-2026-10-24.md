### P2 · `llm/ModelDownloader.kt` — 唯一判据 `inspectExisting()`

**改哪**：`ModelDownloadSpec` 定义、预存 target 分支（当前约 102–116 行）、`companion object`。

```kotlin
data class ModelDownloadSpec(
    val url: String,
    val fileName: String,
    val expectedSha256: String,
    val expectedBytes: Long = -1L,
)

/** 「目标位置那个文件到底能不能用」的判定结果。 */
sealed interface ExistingFile {
    data object Absent : ExistingFile

    data class Usable(val file: File, val bytes: Long) : ExistingFile

    /** 大小或哈希对不上。[actualSha256] 为 null 表示大小就已经不对，没浪费时间读 1 GB。 */
    data class Mismatch(
        val file: File,
        val bytes: Long,
        val actualSha256: String?,
    ) : ExistingFile

    /** 读不了（权限 / IO）。不当作「没有」，也不当作「可用」。 */
    data class Unreadable(val file: File, val reason: String) : ExistingFile
}

/**
 * 判「目标位置那个文件到底能不能用」——**全仓库唯一判据**。
 * 管理器启动校验、下载器开跑前的防御，两处都调它，不许各写一套。
 *
 * 顺序是刻意的：先比大小（廉价，能挡掉绝大多数陈旧/错文件），再算哈希（要读满 1 GB）。
 */
fun inspectExisting(spec: ModelDownloadSpec): ExistingFile {
    val target = targetFile(spec)
    if (!target.isFile || target.length() <= 0L) return ExistingFile.Absent
    val bytes = target.length()
    if (spec.expectedBytes > 0 && bytes != spec.expectedBytes) {
        return ExistingFile.Mismatch(target, bytes, actualSha256 = null)
    }
    val sha = try {
        sha256OfFile(target)
    } catch (e: IOException) {
        return ExistingFile.Unreadable(target, e.message ?: e.javaClass.simpleName)
    }
    val expected = spec.expectedSha256.trim().lowercase()
    return if (sha == expected) {
        ExistingFile.Usable(target, bytes)
    } else {
        ExistingFile.Mismatch(target, bytes, sha)
    }
}

/** 算文件 SHA-256（流式，不整个读进内存）。 */
fun sha256OfFile(file: File): String {
    val digest = MessageDigest.getInstance("SHA-256")
    file.inputStream().use { stream ->
        val buf = ByteArray(BUFFER_BYTES)
        while (true) {
            val n = stream.read(buf)
            if (n < 0) break
            digest.update(buf, 0, n)
        }
    }
    return digest.digest().joinToString("") { "%02x".format(it) }
}
```

预存 target 分支替换为：

```kotlin
// 已有文件先过唯一判据。对上了就直接成功（不碰网络）；对不上就删掉，
// 让本次调用成为「重新下载」—— 陈旧文件占着正式文件名，比没有文件更危险。
when (val existing = inspectExisting(spec)) {
    is ExistingFile.Usable ->
        return ModelDownloadResult.Success(existing.file, existing.bytes, existing.sha256Let())
    is ExistingFile.Mismatch ->
        if (!existing.file.delete()) {
            return ModelDownloadResult.Failed(
                "已存在的模型文件校验不匹配，且删不掉：${existing.file.name}。请清除应用数据后重试",
            )
        }
    is ExistingFile.Unreadable ->
        return ModelDownloadResult.Failed("读不了已存在的模型文件：${existing.reason}")
    ExistingFile.Absent -> Unit
}
```

### P5 · HOLE #3 — 陈旧文件不许冒充就绪，也不许把下载入口吃掉

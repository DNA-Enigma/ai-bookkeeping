# 阿账 · 端侧智能记账管家

基于 **Spark-X2.5-1.7B** 端侧模型的记账应用：说一句话、拍一张小票，账就记好了。模型完全跑在手机上——**离线可用、数据不出设备**。

## 两个版本，怎么选

| | 轻量版 lite（推荐评委用） | 完整版 full |
|---|---|---|
| 安装包大小 | **约 21 MB** | 约 1.1 GB |
| 模型在哪 | 首次进入 App 后一键下载（约 1.05 GB，带进度条、断点续传） | 内置在安装包里 |
| 装完多久能用 | 下载模型后即可用（下载一次永久生效，之后完全离线） | **装完即用** |
| 离线使用 | 下载模型后完全离线 | 完全离线 |
| 适合谁 | 网络下载方便的用户、比赛评审 | 不想等下载、要"开箱即用"的用户 |

> 两个版本**功能完全一样**：对话记账、拍票识别、问账统计、聊天历史、后台问答、离线推理……唯一区别就是模型放哪里。端侧推理、隐私保护、离线可用的特性在两个版本上一致。

## 安装

1. 下载对应版本的 `ai-bookkeeping.apk`（Releases 页，`*-lite` 为轻量版）
2. Android 手机直接安装（需允许"安装未知来源应用"）
3. 轻量版首次打开后按提示下载模型即可；完整版打开即用

## 功能一览

- **说一句记一笔**：「午饭花了 38」→ 自动解析金额、分类，确认即入账
- **拍票识别**：小票/账单拍照，端侧模型提取金额与商户
- **问账**：「这个月吃饭花了多少」→ 本地查账 + 模型总结
- **后台下载 / 后台问答**：下载模型、AI 生成时切后台不中断，回来结果已在
- **聊天历史折叠**：Notion 风格，一轮对话一张卡，点开看详情
- **数据不出设备**：账本、模型推理全部在本机完成，无云端上传

## 技术要点

- 端侧模型：Spark-X2.5-1.7B-Q4_K_M（llama.cpp / JNI，arm64）
- Android 原生（Kotlin + Compose），Room 本地账本
- 模型下载：断点续传 + SHA256 完整性校验 + 前台服务进度通知
- 模型输出容错：非 JSON 输出自动纠错重试 + 降级展示
